# Monday Morning Punchlines — "My Out-of-Office Approved Itself"

One joke about Monday mornings (125 characters, one line) for the make.fun
bounty "Monday Morning Punchlines". `main.py` writes the entry text to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).

The joke: Monday's first email arrives at 06:02, before the alarm, from the
agent's own out-of-office reply — which had approved itself overnight.
